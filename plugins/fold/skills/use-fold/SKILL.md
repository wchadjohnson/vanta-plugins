# Use Fold

Fold turns clothing photos into resale listings. This plugin, **Fold agent**, connects you to Fold
so it can put the seller's ready listings on their marketplaces, such as Depop and Vinted.

Fold gives you every step and checks every result. This skill only helps the seller get set up;
it holds no rules of its own. When the seller asks for something, ask Fold and follow what it
returns.

## Get set up

1. **Connect Fold.** Install the Fold agent plugin, then sign in to Fold when you are asked. Sign-in
   happens on Fold's own page. Never ask the seller to paste a key, password or token.
2. **In ChatGPT: turn on the ChatGPT Chrome extension.** In the extension's settings, turn on
   **Allow access to file URLs**, so listing photos can be uploaded.
3. **In ChatGPT: use Work mode.** In the ChatGPT desktop app, use Work mode for anything that
   happens in the browser.
4. **Choose Always allow.** When asked whether Fold agent may open a marketplace site, download
   a file or upload a file, choose **Always allow**, or every step stops to ask again. On Windows
   expect three prompts on the first run: site access, downloads and uploads.

In Claude: use Claude in Chrome for the browser, with the Fold agent plugin connected.

If Fold's tools are not available, the seller needs to sign in to Fold again (in ChatGPT:
**Plugins → Fold agent → sign in**).

## Bring in photos

If the seller has grouped photos into pieces by file name or folder, hand Fold their paths,
unopened. Only view photos when the grouping is unclear or the seller asks you to look or write copy.
For each piece, tell Fold who writes the copy. If you haven't viewed the photos and the seller
hasn't asked you to write copy, say Fold writes it and send no title, description or price. If you write the copy
yourself, say you are the writer and send all three: title, description and price.
Photos attached in chat can still go to Fold as before.

## First thing to try

Ask: **"Draft my ready Fold listings on Depop."** (or Vinted)

Fold saves your ready listings as private drafts on that marketplace. Nothing goes live unless the
seller asks for it.

## Bring in listings you already have

Ask: **"Import my Depop listings."** (or Vinted)

Fold reads your live listings there, shows one table to approve, and brings them in as Fold pieces
about 20 at a time ("continue" for the next batch). Nothing changes there. Your first 20 imports are
free; after that, each counts like any new piece.
So Fold can tell the same item apart across marketplaces:
- Give every item its own SKU and never reuse one. Vinted has no SKU field: end the description
  with it, e.g. `SKU: ABC123`.
- Use the same first photo for an item on each marketplace.
- Import your main marketplace first. Without SKUs, Fold asks you about more of the rows.

## After a sale

Tell Fold: **"My Fold piece sold on Vinted."** Fold records the sale and lists the other copies of
that piece still on a marketplace.

Going live and removing those copies work the same way: ask Fold, e.g. **"Post my drafts live."**

For each request, Fold hands you the steps one at a time and checks each result before the next.
