# Vinted draft adapter

Creates private Vinted (US) drafts from Fold's `list_ready_listings` payload by filling the
vinted.com sell form and pressing **Save draft**. It never presses **Upload**, which publishes.

- `profile.mjs` — the live-captured form contract (test ids, option ids, limits) and the real-origin
  opt-in, `createAuthenticatedVintedTargetProfile()`.
- `category-ancestry.mjs` — generated by `scripts/build-vinted-category-ancestry.mjs` from Vinted's
  own taxonomy; the picker is walked root -> leaf and Fold sends only the leaf.
- `adapter.mjs` — validates Fold's `marketplace_fields` ids, prepares the draft, reports
  `draft_saved` / `save_failed` / `ambiguous_save` / `blocked_precondition`, verifies the saved draft.
- `browser-capability.mjs` — the form transaction over the shared Layer C driver
  (`../shared/browser-driver.mjs`), reading every value back and refusing Upload on every click.
- `provider-capabilities.mjs` — `createVintedBrowserCapabilityForProvider()`, selecting the driver by
  host transport.

Batches run one draft per host call through `../../workflows/draft-batch.mjs` (photos via
`../../workflows/photo-files.mjs`); Vinted has no bulk/CSV path in the US. The host recipe is in
the `sell-with-fold` skill.
`delist-capability.mjs` deletes an approved sold sibling (draft or published) for `sold-with-fold`.
